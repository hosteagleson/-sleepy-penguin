# 🐧 Sleepy Penguin

**A lightweight desktop shutdown and sleep timer for Linux and Windows.**

> 🚧 **Status: In development — announcement only.** No downloadable application is available yet.

Sleepy Penguin is planned as a simple way to schedule your computer to shut down or go to sleep without memorizing terminal commands. Choose an action, set a timer, and get on with your day.

## Planned Free features

- ⏱️ Set a shutdown or sleep countdown
- 🖥️ Simple graphical interface
- ⏸️ Cancel or change an active timer
- 🔔 Warning before the scheduled action
- 🐧 Linux support first, with Windows support planned

## Exploring for Pro

We are considering optional advanced features, subject to testing and user feedback:

- Monitor network and disk activity while downloads or installations run
- Wait for a selected process to exit before shutting down
- Save reusable shutdown profiles
- Offer safeguards against interrupting active tasks

**Important:** Low network or disk activity does not reliably prove a download or installation is finished. Any smart shutdown feature will need careful testing and clear user controls.
